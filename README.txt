MY PERSONAL WEBSITE
===================

Included pages:
- index.html       Overview / homepage
- german.html      German Learning Center
- exams.html       Exam Center with a saved checklist
- trackers.html    Vacation countdown and manual Christmas ID tracker
- goals.html       Goals and Projects with saved goals
- assets/          Styles and JavaScript

PREVIEW LOCALLY
1. Extract the ZIP file.
2. Open index.html in a modern browser.

PUBLISH ONLINE
- Netlify: Sign in, choose Add new site > Deploy manually, then drag the extracted
  my_personal_website folder (or its contents) into the deploy area.
- GitHub Pages: Upload the extracted files to a repository, then enable Pages
  in the repository settings and select the main branch/root folder.

NOTES
- Checklist items, goals and station tracker entries are saved in the browser's
  local storage on the device/browser where you use the site.
- The Christmas ID tracker is a manual list; it does not automatically monitor
  network announcements.
- The vacation countdown is set to December 18, 2026.
- Google Fonts are loaded from the internet; the site otherwise uses static files.
